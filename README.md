## 🔬 Projects

### 💃 [HAR in Dance](https://github.com/berkaykarak/HAR-in-Dance) · *Deep Learning & IoT · Graduation Project*
Recognizes Turkish folk dances from a wearable network of 5 ESP32 + IMU sensor nodes. Signal filtering, 180 hand-crafted features, and XGBoost / 1D-CNN / CNN-LSTM models; the tuned model reaches **0.90 macro-F1 on dancers it has never seen**. Dataset published on [Kaggle](https://www.kaggle.com/datasets/berkaykarakis/turkish-folk-dance-imu-dataset).
`Python` `PyTorch` `XGBoost` `Optuna` `ESP32`
